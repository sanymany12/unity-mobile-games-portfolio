# Unity Mobile Game Development Portfolio (120k+ Downloads)

Welcome to my mobile gaming archive. This repository serves as a showcase and technical post-mortem for my independent game development portfolio published on Google Play. 

Across multiple published titles, my projects achieved a significant milestone of **120,000+ cumulative downloads** globally.

> ⚠️ **Project Status: Archived**  
> These games were developed using an older version of the Unity Engine (Unity 2017/2018). Due to recent Google Play policy updates regarding legacy Unity engine vulnerabilities and target API requirements, the games have been officially delisted from the store. I have chosen to archive them here as a testament to my full-product lifecycle experience, rather than refactoring the deprecated codebases.

## 🛠️ Technical Implementation & Highlights
Managing these projects end-to-end as a solo developer allowed me to master several core engineering and product management skills:

*   **Performance Optimization:** Wrote highly efficient C# scripts to maintain a stable 60 FPS across low-end Android devices, managing memory allocation and garbage collection.
*   **Asset & Resource Management:** Optimized 3D/2D assets, texture atlases, and audio compression to minimize the final APK build size.
*   **Third-Party SDK Integration:** Implemented and configured mobile advertising networks, analytics trackers, and privacy policy compliance models.
*   **Product Lifecycle:** Handled everything from prototyping, mechanics design, UI/UX implementation, store listing optimization (ASO), to community feedback management.
